> 02_LA_ELECCION: ¿QUÉ ES LA MATRIX?

Estrenada en 1999, The Matrix plantea que el mundo que percibimos es en realidad una simulación interactiva creada por máquinas para mantener controlada a la humanidad.

Thomas Anderson, un programador de día y hacker conocido como Neo de noche, descubre la verdad gracias a Morpheus y su tripulación.

> 03_PARALELISMO: MATRIX VS. DESARROLLO WEB

Más allá de la ciencia ficción, la película representa visualmente cómo funcionan los sistemas informáticos y las páginas web que construimos hoy:

01. Código Verde = Backend

Los habitantes ven edificios y calles (la interfaz visual), pero los operadores ven cascadas de código. En la web, el usuario ve el diseño, pero detrás corren HTML, PHP y bases de datos.

02. La Simulación = El DOM

La Matrix renderiza objetos en la mente conectada. De forma similar, el navegador lee nuestro código fuente y renderiza el DOM (Document Object Model) en pantalla.

03. Agentes = Firewalls

El Agente Smith patrulla el sistema buscando anomalías para eliminarlas, funcionando igual que un Firewall o sistema de seguridad bloqueando accesos no autorizados.

04. Dejà Vu = Bugs / Caché

En la peli, un déjà vu ocurre cuando las máquinas alteran el código en vivo. En diseño web, es el clásico glitch visual o un problema de caché al actualizar un archivo.

> 04_PROGRAMAS_DE_CARGA: MÓDULOS DE ENTRENAMIENTO
